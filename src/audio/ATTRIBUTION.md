# Audio Attribution & Licensing Note

The audio cues in this directory were generated mathematically in Node.js using 16-bit PCM RIFF WAV synthesis:

1. **`popup.wav` / `preview-found.wav`** (30.9 KB): Dual-frequency harmonic chime (C5 523.25 Hz + G5 783.99 Hz with exponential decay) played on modal popup appearance.
2. **`redo.wav` / `apply.wav`** (24.7 KB): Affirmative ascending chirp (D5 587.33 Hz rising to A5 880.00 Hz with fast attack and smooth decay) played on Redo repair.
3. **`undo.wav`** (24.7 KB): Gentle descending tone (E5 659.25 Hz descending to A4 440.00 Hz with soft decay) played on Undo repair.
